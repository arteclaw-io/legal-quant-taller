# Legal Quant

Herramientas jurídicas con IA, con la spec primero. Cada herramienta tiene su spec, sus cambios registrados y su verificación.

```text
AGENTS.md              reglas del proyecto para cualquier IA
ARCHITECTURE.md        decisiones y camino de crecimiento
verificar.md           ejemplos calculados a mano
tools/
  fee-calculator/      calculadora de honorarios (Ley 27.423, art. 21)
    SPEC.md            la fuente de verdad
    intents/           un archivo por cada cambio, con fecha
  _template/SPEC.md    esqueleto para una herramienta nueva
```

Las herramientas son estimaciones de apoyo y no reemplazan el criterio profesional.
